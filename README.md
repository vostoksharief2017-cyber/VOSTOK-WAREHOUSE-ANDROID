# VOSTOK-WAREHOUSE Android — .NET 10

This version is updated from .NET 8 to .NET 10 because .NET 8 MAUI is out of support.

Features:
- Hikvision RTSP live camera view
- Door 1, 2, 4 and 5 ISAPI control
- Door 3 permanently disabled
- No TALK button
- No SIP
- No microphone

Configured devices:
- WH7 / Door 1: 192.168.5.131
- WH9 / Door 2: 192.168.5.133
- Door 3: DISABLED
- WH4 / Door 4: 192.168.5.134
- WH5 / Door 5: 192.168.5.132

GitHub:
1. Replace the old project files with all files in this ZIP.
2. Commit to main.
3. Open Actions.
4. Select Build Android APK.
5. Run workflow.
6. Download VOSTOK-WAREHOUSE-Android-APK from Artifacts.

Do not store the real Hikvision password in GitHub. Enter it in the app.
