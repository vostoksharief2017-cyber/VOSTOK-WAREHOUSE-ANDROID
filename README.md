# VOSTOK-WAREHOUSE Android
Android app with Hikvision RTSP live view and ISAPI door control. TALK/SIP/microphone is intentionally excluded. Door 3 is permanently disabled.

Device IPs:
WH7 / Door 1 = 192.168.5.131
WH9 / Door 2 = 192.168.5.133
Door 3 = DISABLED
WH4 / Door 4 = 192.168.5.134
WH5 / Door 5 = 192.168.5.132

Enter the Hikvision admin password in the app. Do not put real passwords in GitHub.

Build: GitHub Actions -> Build Android APK -> Run workflow -> download the VOSTOK-WAREHOUSE-Android-APK artifact.
